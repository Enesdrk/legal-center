# Legal Center

Centralized legal and support pages for [FallenApps](https://enesdrk.github.io/legal-center/) mobile apps.

Live site: https://enesdrk.github.io/legal-center/

## SEO

- `robots.txt` and `sitemap.xml` at repo root (GitHub Pages).
- Per-page meta, Open Graph, canonical URLs, and JSON-LD: run `node scripts/apply-seo.mjs` after editing legal HTML or `apps/apps.json`.
- Regenerate sitemap: `node scripts/generate-sitemap.mjs`.

See [docs/seo-maintenance.md](docs/seo-maintenance.md), [docs/search-console-and-social.md](docs/search-console-and-social.md).
