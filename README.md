# Legal Center

Centralized legal and support pages for [FallenApps](https://enesdrk.github.io/legal-center/) mobile apps.

Live site: https://enesdrk.github.io/legal-center/

## SEO

- `robots.txt` and `sitemap.xml` at repo root (GitHub Pages).
- After editing legal HTML or `apps/apps.json`, run `node scripts/apply-seo.mjs` and `node scripts/generate-sitemap.mjs`.

## App registry

All apps and store links: [`apps/apps.json`](apps/apps.json).
